# CyberWatch — Cybersecurity Monitoring Dashboard

Real-time SOC-style security dashboard built with Python Flask, psutil, and Chart.js. Features a matrix rain background, glowing live metrics, animated alert feed, and SSH brute force simulation.

## Features
- Live CPU, RAM, and network I/O from real system data
- Matrix rain canvas background
- Animated scrolling threat ticker
- Color-coded threat level indicator
- Live auth log feed with slide-in animations
- Failed login bar chart with threat-level coloring
- Blocked IP list with hover effects
- Nmap-style open port display
- Full dark SOC-style UI with glow effects

## Tech Stack
- Python / Flask
- psutil
- Chart.js
- HTML / CSS / JavaScript
